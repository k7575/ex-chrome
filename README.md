# WebAssembly Wallet Generator Chrome Extension

A lightweight, secure Google Chrome extension that generates Ethereum and Solana wallet addresses locally using Rust compiled to WebAssembly (Wasm).

## Features

- **Multi-Chain Support**: Generate Ethereum (0x) and Solana (Base58) keypairs.
- **High Security**: Private keys are generated entirely client-side using Rust's secure random number generators. No external API calls.
- **Persistent History**: Saves generated wallets locally in the browser's storage until manually cleared.
- **Native Performance**: Leverages WebAssembly for cryptographic operations.

## Project Structure

- `popup.html`: The popup user interface.
- `popup.js`: JavaScript controller handling DOM events and WebAssembly initialization.
- `src/lib.rs`: Rust source code utilizing `ethers` and `solana-sdk` libraries.

## Prerequisites

To build this project from source, you need to install:

1. [Rust and Cargo](https://rustup.rs)
2. [wasm-pack](https://github.io)

## Build Instructions

1. Clone this repository.
2. Initialize and compile the Rust code to WebAssembly for bundlers/browsers:
   ```bash
   wasm-pack build --target web
   ```
3. Ensure your `manifest.json` file is present in the root directory (specifying `popup.html` as the default popup).

## Installation in Chrome

1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Enable **Developer mode** using the toggle switch in the top-right corner.
3. Click on the **Load unpacked** button in the top-left corner.
4. Select the root folder containing the extension files (`popup.html`, `popup.js`, and the compiled `pkg` folder).

## Security Warning

This extension is intended for educational purposes or testing development networks. Never use a wallet generated by a public or third-party web extension for storing real, high-value mainnet funds without auditing the source code.
